Phần 1: Inline Style

Đoạn văn này được định dạng màu sắc bằng Inline Style trực tiếp trên thẻ.

Phần 2: Internal Style

Đoạn văn này được định dạng màu sắc bằng Internal Style (nằm trong phần head).

Phần 3: External Style

Đoạn văn này được định dạng màu sắc bằng External Style (liên kết với file style.css riêng).
