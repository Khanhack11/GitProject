SASS Mixins & Variables

Thực hành: Tạo Mixins & Biến Tối Ưu CSS

Website Mẫu Áp Dụng Kiến Trúc SASS Chuẩn

📦 Component Card 1: Khái niệm & Mục tiêu

Trong CSS truyền thống, việc lặp đi lặp lại các thuộc tính như kích thước chữ, màu sắc, đổ bóng và khoảng đệm làm mã nguồn cồng kềnh và khó bảo trì. Với SASS, chúng ta định nghĩa biến (Variables) và Mixins để kiểm soát toàn bộ giao diện từ một nơi duy nhất.

🎨 1. Biến (Variables)

Tập trung toàn bộ giá trị dùng chung vào abstracts/_variables.scss:

$primary-color: red; $text-color: #222; $font-large: 32px; $font-medium: 28px; $padding-standard: 10px 20px; $box-shadow-default: 2px 2px 10px rgba(0, 0, 0, 0.1);

⚡ 2. Mixins Tái Sử Dụng

Đóng gói các khối style có thể tái sử dụng vào abstracts/_mixins.scss:

@mixin button-style($bg-color) { background: $bg-color; color: white; padding: $padding-standard; border-radius: 5px; } @mixin box-style { background: white; padding: 15px; border-radius: 10px; box-shadow: $box-shadow-default; }

🎯 Kết Quả Đạt Được

  • Gọn gàng & Dễ quản lý: Các module được chia tách rõ ràng thành partials (_variables.scss, _mixins.scss, _typography.scss, _buttons.scss, _cards.scss).
  • Dễ dàng thay đổi theme: Khi muốn đổi màu chủ đạo (ví dụ từ red sang blue) hoặc cỡ chữ, chỉ cần đổi giá trị của biến một lần duy nhất.
  • Import tập trung: Được quản lý thống nhất qua main.scss.
